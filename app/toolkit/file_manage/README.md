# 文件操作器

通过完整路径查看属性/目录，创建目录、复制、移动、重命名、编辑普通文本、移入回收站。编辑前自动快照，不永久删除。

## 示例

```json
{
  "action": "info",
  "path": "C:\\\\资料\\\\说明.md"
}
```

参数按 manifest.json 定义。工具统一适用于所有模型；调用额度由工作台设置控制。工具参数应来自用户输入或实际读取结果，不猜路径。

编辑全文使用text；定点替换使用find/replace。复制移动传path、directory、name；新建目录传directory/name。快照时间线在任务与访问日志查看。Windows回收站不可用时操作失败，不尝试永久删除。
