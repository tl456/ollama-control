# 网络请求

访问HTTP/HTTPS网页或本机/局域网API。支持方法、请求头、JSON、正文及下载。不自动重试写请求。只返回有界正文，不返回凭据头。

## 示例

```json
{
  "url": "http://127.0.0.1:11436/api/tags",
  "method": "GET"
}
```

参数按 manifest.json 定义。工具统一适用于所有模型；调用额度由工作台设置控制。工具参数应来自用户输入或实际读取结果，不猜路径。

凭据可在工具设置中限定主机；请只在可信目标发送资料。网络返回正文可能包含隐私，工作台审计仅记录目标主机、方法、状态与耗时。请求超时不表示服务端没有执行写入，先核实结果再决定是否重新请求。
