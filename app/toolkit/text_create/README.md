# 新建文本文件

在指定完整目录创建一个TXT或MD文件。只新增，重名自动编号，不覆盖。返回最终文件路径。

## 示例

```json
{
  "directory": "C:\\\\资料",
  "name": "说明",
  "format": "md",
  "text": "# 说明\\n内容"
}
```

参数按 manifest.json 定义。工具统一适用于所有模型；调用额度由工作台设置控制。工具参数应来自用户输入或实际读取结果，不猜路径。

文件名不包含路径，directory使用完整目录。默认UTF-8，发生冲突创建名称 (2).md 等文件。此工具没有覆盖接口。
