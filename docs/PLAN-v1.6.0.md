# 本地智能工作台 1.6.0 实施与验收计划

日期：2026-10-30（北京时间）。状态：实施中。基线：1.5.1，Git 提交 cb039b8。用户已授权实施、独立 QA、完整且快速验证、本地双形式交付和 GitHub 更新。阶段开始/结束、整合、构建及发布前回读本文件，逐项填写证据。

## 边界与交付

- 所有模型统一工具、参数、功能和调用额度；不做模型强弱分类，不按本地/云端裁剪工具。保留原生/传统协议选择，图片请求失败如实报告。
- 不增加旧版本兼容分支。保持用户配置、模型和业务数据；本轮未要求出厂，测试全部使用隔离合成数据。
- 不读取真实企业文档、历史聊天、密钥作为开发素材。不绕过企业透明加密；Python 与独立读取程序检查可读性、UTF-8、TSD 头、ZIP CRC/SHA256。
- 公共源码、Git 署名、GitHub 包统一 tl456；本地发行署名使用私有构建参数，值不进入公共源码/提交/测试/报告。第三方许可保留。
- 保留 qwen3.5:9b、qwen3.5:4b、qwen3-embedding:0.6b 及完整官方运行库。交付离线直接运行目录/压缩包与安装 EXE+BIN 目录；GitHub 更新源码及通过验收的公开发行。
- 不停止不属于本软件的服务，不覆盖原有公开发行。端口、进程、包均核验身份。浏览器/实机/CAD未实际验证之项明确记录，不以 mock 冒充。
