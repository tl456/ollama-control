# 升级与目录结构

本说明对应公开版1.5.1。程序与资料集中管理，但公开源码、个人配置、运行数据、模型和用户插件各有目录。

## 目录及保留边界

| 位置 | 内容 | 升级时的处理 |
|---|---|---|
| `app/`、`web/`、`presets/`，或发行版EXE与`_internal/` | 程序、界面和内置预设 | 使用同一发行版本的完整程序替换 |
| `config/`，含`tools/`与认证文件 | 个人设置、工具偏好、密钥与认证状态 | 默认保留已有值，仅补缺失默认项 |
| `data/` | 聊天、附件、Markdown记忆、知识库及Python实验 | 不因版本改变自动清空 |
| `models/`、`runtime/` | 模型与运行资源 | 按官方来源及发行清单维护，不混入个人文档 |
| `plugins/imported/` | 用户导入插件 | 不被内置样例覆盖 |
| `logs/`、`cache/` | 日志和派生缓存 | 按设置的期限、体积和引用关系清理 |

公开源码不包含个人运行目录。不要用开发机的`config/`覆盖其他用户设置，也不要把整个工作目录直接提交到GitHub。内置预设可能随版本更新，自行修改的扩展应另行保存。

## 默认保留升级

**公开发行版默认使用`preserve`。** 版本变化时保留已保存的设置、聊天、记忆、知识库、工具、密钥、插件和模型；缺少的新设置使用当前默认值。同版本普通重启也保留资料。配置格式损坏或遇到不符合要求的链接路径时，应明确报错，不能用静默清空掩盖问题。

升级前从托盘正常退出，等待运行任务和受管理后台结束，再替换完整程序文件；不要强行结束不属于本工作台的Ollama。重要资料请先自行备份。默认保留行为不能代替备份，也不保证跨版本任意手工修改都兼容。

“恢复出厂设置”与升级是两件独立操作。手动初始化需要界面确认，会清除软件管理的资料和设置，不创建备份；模型、运行库和外部原件保留。操作前请核对提示列出的范围。

源码保留显式`LOCAL_AI_UPGRADE_MODE=test-reset`供隔离测试使用。它会在版本变化时清空软件自管资料，不能用于日常资料目录或作为公开版默认启动方式。

## 模块组织

- `app/server.py`和`app/api/`：Web入口、中间件、接口及服务装配。
- `app/toolkit/<工具ID>/`：每个工具的实现和说明；`registry.py`汇总定义，公共服务复用文档、Office、附件与Python逻辑。
- `app/memory.py`：固定单份记忆、保存限额、串行与原子写入。
- `app/knowledge.py`、`kb_documents.py`、`rag_chunks.py`、`rag_query.py`：知识库生命周期、索引、标题分段与查询提取。
- `app/providers.py`、`network.py`、`service_config.py`：模型适配、进程归属、认证和服务角色。
- `app/turn_queue.py`：同对话待发与取消；`upgrades.py`、`lifecycle.py`：升级、初始化与清理。
- `web/modules/`：前端公共模块；`app.js`和`workspace.js`负责页面编排。
- `plugins/examples/`：可供阅读和二次开发的可信示例；不是用户插件安装目录。

工具使用当前定义与统一执行入口。界面和所有业务API采用统一可选密码策略；内部生命周期控制凭据不作为普通网页登录入口。

## 清理与共享

新安装默认最多30个活动对话；满额提示用户手动移入回收站，已有对话仍可发送。回收站默认30天、日志默认7天；Python实验默认7天/最近30次，无引用附件有宽限期。实际设置可改，清理不处理外部原件或仍被引用的数据，也不等于底层安全擦除。

网页8765、共享模型网关11436、自管聊天11437、嵌入11438分别管理。共享工作空间不是多用户隔离；远程完整权限可能读取或修改宿主资源。详情见[安全说明](../SECURITY.md)与[隐私说明](../PRIVACY.md)。

## 构建与验证

通用构建步骤见[构建说明](../packaging/构建说明.md)。完整安装版的EXE与全部BIN保持相邻；解压版保留完整`LocalAIStudio`文件夹。模型、运行库、分词与第三方许可应按实际清单验证。

源码语法、合成测试、真实模型、云接口、Office COM、原生窗口、安装卸载和第二物理机分别记录。独立进程读取一致或未发现保护头，不是企业透明加密已被消除的证明；不修改企业安全软件或保护策略。程序不自动创建系统自启动项，自启动由使用者自行选择和管理。
