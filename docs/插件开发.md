# 迷你工具插件接口 v1

适用于公开版1.5.1。发布插件前阅读[安全说明](../SECURITY.md)与[隐私说明](../PRIVACY.md)。

本软件采用类似 Open WebUI 工作空间的 ZIP 导入体验，不直接兼容任意 Open WebUI Python 工具。

ZIP 根目录需要 `manifest.json` 与 `tool.py`，可以附加 `README.md`。工具包最大 20 MiB，展开最大 40 MiB。导入不执行代码，首次导入默认停用；启用前检查源码和来源。

```json
{
  "id": "demo_tool",
  "name": "示例工具",
  "version": "1.0.0",
  "description": "说明何时使用，不假装拥有未实现能力",
  "entrypoint": "tool.py",
  "parameters": {
    "type": "object",
    "properties": {"query": {"type": "string"}},
    "required": ["query"],
    "additionalProperties": false
  },
  "permissions": ["example.read"],
  "timeout": 10,
  "settings_schema": {
    "type": "object",
    "properties": {
      "prefix": {"type": "string", "title": "返回前缀", "default": "DEMO", "description": "测试时显示的标记。"}
    },
    "additionalProperties": false
  }
}
```

```python
def run(arguments, context):
    prefix = context.get("settings", {}).get("prefix", "DEMO")
    return {"label": prefix, "query": arguments["query"]}
```

`context` 提供用户已配置的 `roots` 和该插件自己的 `settings`。插件的独立配置保存在 `config/tools/<工具ID>.json`，不要把 API 密钥等敏感值作为普通插件配置保存。界面的“配置”按 Schema 渲染；支持基本字符串、数字、布尔、枚举以及 JSON 对象/数组。

参数由 JSON Schema 校验；只有聊天勾选且已启用的工具才能被调度。单轮最多 4 次调用。插件进程最长 30 秒，默认 10 秒，返回 JSON 最大约 64 KB；不自动安装依赖。扩展包只能使用随软件提供的 Python 依赖或自行约定的明确外部程序。

导入时保存文件哈希；文件变更后应重新导入、审查、启用，不能在不提示的情况下替换原工具。

独立进程只解决生命周期和超时，不是安全沙箱。原生插件可以自行调用 Python 的文件或网络功能，声明的权限不能阻止恶意代码；只导入可信内容。重命名等写入插件属于后续扩展，不是当前内置能力，开发时必须另行实现范围限制、目标展示、冲突处理和用户确认。

## 时间工具示例

`plugins/examples/time_demo/`提供完整的时间工具示例、manifest、中文注释、教程和MIT声明。将该目录中的文件置于ZIP根目录后导入工具工作空间；导入后先检查源码，再启用并在对话中勾选。只修改这个插件的配置，不应通过导入包覆盖其他工具或用户设置。
