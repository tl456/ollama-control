# 软件教程

本指南对应公开版1.6.0。工作台通过Python服务连接Ollama或你设置的远程模型，资料集中保存在运行目录。先阅读[安全说明](../SECURITY.md)、[隐私说明](../PRIVACY.md)与[免责说明](../DISCLAIMER.md)。

## 1. 第一次启动

发行包按README启动；源码先完成Python环境和官方Ollama准备。完整离线发行物是否包含9B、4B和0.6B，应以Release实际清单为准。源码仓库只有程序和预设，不包含已下载模型。

进入界面后先确认“本地服务已连接”。模型中心可以查看引擎版本、模型列表和下载进度。首次已知专用显存大于10GiB优先9B，其余或未知选择4B；默认8K上下文，不做高上下文试载。首次回答加载模型会更慢。

窗口默认工业深色。默认使用Edge/Chrome应用窗口，隐藏地址栏。设置可切换WebView2或普通浏览器；首次启动、托盘重新打开采用同一设置，首选不可用时回退到浏览器。关闭内嵌窗口默认缩到托盘；关闭浏览器标签不代表停止后台。真正退出请使用托盘菜单。工作台不自动设置开机启动，也不接管其他Ollama进程。

## 2. 模型可以完成什么

下表只是尝试方向，不是准确率、资格或智能保证。使用之前应先确认模型实际存在并符合许可。

| 模型 | 可先尝试 | 必须另行核对 |
|---|---|---|
| Qwen3.5 2B | 给少量文件名分类，改写短通知，提取明确字段 | 多步骤条件、长文综合和计算容易遗漏 |
| Qwen3.5 4B | 查找某类文件，比较两段短说明，生成目录分类建议，描述截图 | 不能仅凭文件名认定内容、版本或合格性 |
| Qwen3.5 9B | 对照几份短资料，整理差异与待办，解释操作步骤 | 工程数据、长文推理和代码仍可能出错 |
| Qwen3.5 27B | 尝试较长资料综合与复杂步骤说明 | 内存和等待成本更高，不能保证结论正确 |

“整理目录”可以生成建议，也可在勾选文件操作器后执行重命名、移动等操作。目录清单、搜索、属性、文件读取仍是只读工具。工具卡片的蓝色标签区分创建、编辑、回收站和联网能力；执行结果以工具记录为准。

## 3. 理解上下文

上下文是模型本轮能同时使用的容量，提示词、历史、附件、图片、记忆、检索片段、工具结果和回答都占位置。

| 容量 | 便于感知的场景 |
|---|---|
| 2K | 一张交接班便签；一条设备报修信息 |
| 4K | 一份维护通知；一个简单工序的操作说明 |
| 8K（默认） | 一次故障经过记录；一份简短试验说明 |
| 16K | 含表格的试验大纲；会议纪要与行动清单 |
| 32K | 几份相关工艺说明、检验要求和网页摘录 |
| 64K | 一本设备手册的主要文字；一份工装改进资料 |
| 100K | 一个维护专题的手册摘录、故障记录和交接说明 |
| 128K | 一个零件试制专题的需求、试验记录与会议资料 |
| 200K | 一组相关零件的多阶段工艺和试验资料 |
| 256K | 一个小型制造专题的多份文档、记录和参考网页 |

以上只是类别类比，不是精确换算。同名资料的长度差别也很大；不同语言、代码和图片消耗不同。1K=1024 Token，速度仍用Token/s。更大上下文通常更占内存/显存，不会自动让模型更聪明。

默认允许手动选择超过32K，但不会自动从8K变成100K。允许自定义超过模型声明窗口的容量，不因声明值直接拒发；回答预留和资源余量检查继续生效。服务端是否接受由模型/API决定，报错不会触发反复降级。256K声明不等于本机稳定跑满，也不存在固定“输入236K就安全”的保证。

默认约80%后摘要旧历史，近期原文目标约10%，也可改截断或手动。聊天顶部“上下文 / 摘要”可查看实际摘要、覆盖条数及容量，UI标记压缩过程，原聊天不因此删除；摘要可能遗漏，应核对关键版本、单位和条件。需要一次分析较多附件时可选“单次资料分析”减少历史，仍不能绕过总预算。

## 4. 聊天与待发队列

新建对话后输入明确任务，例如“把这三条合成故障记录整理为待办”。支持Markdown、代码、表格等显示。聊天正文和输入区按宽屏自适应；右侧刻度显示当前对话的提问摘要，点击定位到相应历史页，回到底部返回最新内容。生成期间查看历史不会打断回答。用户消息可编辑并形成分支，回答可重新生成；对话可搜索、分页、置顶、改名、导出和移入回收站。

同一对话正在回答时，仍可继续发送下一条。“发送”和“停止回答”分开；后续消息在待发区显示，可编辑或取消。前一轮完成后才处理下一条，让它能使用已完成的回答。

待发保存模型、上下文、工具、附件和技能等选择。权限或功能关闭仍即时生效。停止或失败后依赖的后续任务暂停，用户决定继续；重启不静默重放。每个对话最多8条待处理，全局队列也有上限。

页面断开不表示后台已停。回包丢失时先看任务列表，避免盲目重复提交。模型口述“已完成”也不等于真正调用过工具；以工具卡片、结果文件和复核范围为准。

## 5. 附件与原件

TXT、MD、Word、Excel、PPT提取文字；DAT等未知扩展先检查是否为可读文本。Excel/PPT提取文字与单元格内容，不完整还原排版或重算公式。图片可OCR，也可选原图交给支持图片的模型；OCR可能识错，发送前可预览。

手动附件默认Python直接读取，可在设置切换Office COM。只读文件工具有独立读取设置，默认COM。COM需要安装相应Office并拥有读取权限；以只读、禁宏、不保存原件方式调用，但不能保证第三方Office或企业透明加密策略的所有行为。

超长文字按本轮输入预算截取，并显示送入范围。原件及提取全文可保留，不代表本轮模型看到了全文。可减少附件、指定范围、分段读取或生成摘要；一次读出结果不保证模型已经正确分析所有内容。

选择云或远程模型后，所用附件文字、OCR结果和原图可能发给该连接。COM可读并不代表内容获准外发。

## 6. 工具、技能与Python

在工具工作空间打开对应工具的设置，可点击“选择文件夹”填写起始目录，也可输入完整路径。起始目录用于浏览，不是读取白名单；实际权限由当前Windows账户与工具开关决定。

工具工作空间管理工具自己的起始目录、搜索深度、读取方式和开关。起始目录是便利偏好，不是安全白名单。

- 时间：读取宿主机日期、时间与时区；自动注入时间和模型实际调用TIME工具的记录分别显示。
- 目录、属性与搜索：列出名称、类型、大小、修改时间，按文件名和配置深度查找；有分页、数量、输出与超时限制。
- 文件读取：传当前账户可读的完整路径；支持文本、Office和OCR，可按范围、行或分段返回实际位置与下一段。
- 本对话附件：先列附件编号，再读取相应原件或ZIP条目；只能使用当前有效分支中已发送的附件。
- Python：默认功能可用，新对话不勾选；需要时明确选择。可计算、解析和生成文件，超时与输出有上限，但拥有当前账户权限，不是安全沙箱。

技能中心支持新建、编辑、复制、删除以及MD/ZIP导入导出。仅预设一个通用“资料核对与结果整理”示例，复制后自由编辑。在输入框“＋→使用技能”选择规则，后续发送时生效，不自动授予工具权限。详见[技能教程](技能教程.md)。

工具调用可选原生调用、传统JSON、自动或关闭。原生方式需要模型实际支持；传统方式由模型按约定返回JSON，再校验并执行。所有模型使用统一工具、参数和功能，不按本地/云端或模型强弱裁剪。默认每条用户消息累计最多50次实际调用（失败也计数），设置中可调；自动注入时间不计数。模型仍可能漏调用或填写错误，达到额度后保留已有结果。

工具卡片支持导出ZIP，包含代码与说明，不包含已保存的密钥或运行数据；内置工具的导出适配包依赖同版本工作台共享服务。可下载“工具接口测试示例”，导入后先在参数测试器核验正常与异常返回。导入ZIP插件前检查来源和代码。插件可写文件或联网，声明权限、独立进程和超时不能代替系统隔离。详见[插件开发](插件开发.md)。

### 新建文本、文件操作与快照

“新建文本文件”只在指定目录新增TXT/MD，重名自动编号，返回最终路径，不覆盖原件。“文件操作器”可建目录、复制、移动、重命名、编辑文本和移入Windows回收站。回收站不可用时返回失败，不退化成永久删除。

文件级编辑任务开始前保存修改前快照；同一任务修改同一文件多处只保存一份，再次编辑产生新时间点。默认保留最近100份，并有总容量限制，在文件操作器配置中调整。“任务与访问日志→文件快照”支持分页时间线与恢复；恢复前保存当前状态。

### Office操作器：内容、格式、图片与预览

先用inspect读取结构，再用edit指定段落、工作表单元格、幻灯片和形状。支持新建、复制、内容与常用格式修改、图片插入及排版预览。同文件可批量修改，所有模型使用同一套操作。

图片可来自路径或附件编号；默认嵌入文档、保持比例。Word可定位段落或单元格，Excel可定位区域，PPT可定位页面与形状位置。实际动作、字段和例子以工具参数说明为准。fonts返回本机字体，界面可演示示例文字。

预览由本机Office实际导出，工具结果可点“查看排版效果”，支持翻页、放大和下载。界面显示预览方法：整页、打印页或工作表区域图像应分别理解。只生成相关范围，不能把区域预览当作全文检查。保存结果和预览失败分别显示。

前端预览不等于模型已看过图片。模型可显式请求预览图用于回看；图片会按当前模型连接发送，接口不支持时如实报错。文档编辑与插图本身不依赖模型看图。实际保存后检查文件与返回信息；版式效果需要结合预览核对。

### 网络与本地API

网络工具支持HTTP常用方法、JSON、请求头、正文提取和下载，可访问本机及局域网API。可配置代理、超时和返回容量。请求可能向目标地址发送资料，工具卡片以蓝色标签说明。凭据用配置引用，避免写入模型可见参数；写请求超时不自动反复执行。

### 工具审计

“任务与访问日志→工具审计”分页显示模型、连接、工具动作、结果和耗时，支持筛选。仅记录执行元数据及脱敏目标，不记录聊天、文档正文、完整代码或密钥。保留最长365天且总计不超过1GB，达到任一条件清理最旧记录；不提供清空按钮，出厂设置保留。自由Python内部每个系统操作不一定能单独审计。

## 7. 知识库RAG

知识库分资料管理、处理维护、检索测试和嵌入模型等区域。新建库并添加资料，等待异步索引完成，再在聊天中选择使用。默认本机`qwen3-embedding:0.6b`、每段512 Token、重叠64、Top K 2，嵌入偏好CPU。

默认“自动检索·原始模式”：先用当前聊天连接提取问题与关键词，再查向量和关键词索引，将相关片段及来源加入本轮。提取提示词可编辑、恢复默认、测试或关闭；失败回原问题。这与普通工具的“传统JSON”模式不同。

“按需检索·原生调用”由支持工具的模型决定检索，不保证它一定调用。检索摘要可展开美化详情，查看原问题、实际关键词、来源文件/标题/范围、分数、正文和原始JSON。分数不是正确率，找不到资料和模型理解错误也应分别判断。

Markdown默认按标题和段落预分节，再按Token分段。可以新建或导入可编辑MD，左编辑右预览，保存后异步索引；新完整索引完成才切换。删除文档后立即不再检索，旧任务不能复活它。

更换嵌入模型或分段设置需要重建。已有库不会因为修改新建默认值而偷偷切换；失败时保留上次完整索引并提示。RAG只提供部分相关片段，不能冒充已读取全文，也不能代替精确计算。

## 8. Markdown记忆

所有对话共用`data/memory/memory.md`。默认允许AI自由增量或完整编辑，也可人工修改。适合长期偏好、术语和明确事实，不适合密钥、完整资料库或临时猜测。

AI使用`memory_read`和`memory_update`；保存串行且原子化。完整覆盖按最后成功保存生效，两个对话基于旧全文编辑仍可能互相覆盖，不承诺自动语义合并。

默认保存硬限额1K（1024 Token，含注入包装），另有16KiB字节保护；设置可改。超限不覆盖原文，返回用量、限额及精简提示；外部编辑或下调阈值导致旧文件超限时保留原件，聊天按预算截取并提示。分词不可用时用标明的估算，云端计数可能不同。

记忆会随当前聊天请求发给所选模型。切换云或其他主机前，应确认记忆适合发给对方；不需要时可关闭。

## 9. 云模型与思考档位

设置中添加云连接，填写官方接口根地址、实际可用模型名与密钥。OpenAI兼容并不保证支持所有图片、工具和思考参数，应按服务商能力声明。

支持思考档位时，聊天输入区显示滑杆。DeepSeek预设按连接能力提供关闭/low/high/max；通用服务仅显示显式声明的档位，medium也需服务支持。通用off标为“服务默认”，表示不提交深度参数，不保证关闭服务端思考。

本对话可覆盖连接默认，待发保存参数快照；思考内容可折叠。更深思考可能增加费用和等待，不保证更准确。模型名称、价格与能力可能变化，应以服务商当时文档为准。云连接会接收本轮所用消息、附件、记忆、检索片段和工具结果。历史消息尽量保持稳定以利于服务端缓存复用，速度与用量中显示可得的缓存命中和整轮请求数量；实际命中率由服务端决定。

## 10. 局域网、模型API与登录

| 入口 | 默认端口 | 默认行为 |
|---|---|---|
| 工作台网页 | 8765 | 仅本机 |
| 共享模型网关 | 11436 | 关闭，要求Bearer密钥 |
| 本机聊天引擎 | 11437 | 仅本机 |
| 本机嵌入引擎 | 11438 | 仅本机 |

端口冲突时按+1寻找可用端口，并跳过本工作台其他服务角色。启动时提示实际地址，诊断和接口教程显示实际端口；不要只依赖上表默认值。外部Ollama地址不会自动修改。

网页和模型网关分别设置。网页无密码时直接进入；设置密码后各入口统一Cookie登录。记住设备会保存有期限的会话，后台重启不清仍有效的登录；退出登录或改密码会撤销相应会话。

共享网页是同一工作空间，不是多人隔离。普通远程权限受限；宿主机可另行开启远程完整控制。开启后，能访问并按密码设置登录的客户端可使用宿主文件、COM/Python及管理能力；未设密码则无需登录。只能向可信设备开放。

模型网关先生成密钥，再启用共享。Open WebUI等客户端填写界面显示地址，OpenAI兼容路径加`/v1`。网关不执行宿主文件或代码工具；直连11437原生API绕过网关的日志、排队和资源门禁。

访问记录按页显示来源IP、接口、模型、状态、耗时和可得用量。程序/引擎错误日志或文件路径仍可能含敏感信息，复制分享前须检查。HTTP不加密，不应直接公网映射；公网需另配HTTPS/VPN与访问控制。

## 11. 设置、性能与排障

整体缩放50%–200%，模型状态、工具、RAG及侧栏可折叠并按设备记忆。导航与最近对话间分隔条可拖动，长列表分页、独立滚动；设置保存按钮保持可达。

设置→诊断查看版本、服务归属、模型加载、设备、内存显存、队列与索引。复制使用脱敏接口，但分享前仍应检查。刷新不绕过监测退避。已结束的下载可关闭提示或清除记录，不删除模型层，可再次下载。

聊天“自动”交给Ollama分配GPU/混合/CPU，也可选仅CPU；自动反复降级默认关闭。嵌入默认CPU，可选优先GPU并与聊天共用资源队列；预检不足转CPU，GPU失败最多一次CPU兜底并提示，不往返重载。偏好改变不代表已加载模型立即切换。

NVIDIA监测有缓存、超时和退避，异常时暂停。不确定时先停止任务、减小上下文、减少附件或手选4B，再查看系统提交量和驱动状态。软件不修改分页文件或安全软件；不要为误报全局关闭防护或反复高负载试载。

## 12. 数据维护与更新

公开版升级默认保留资料。更新前正常退出并自行备份重要数据；手动出厂初始化才会按界面确认清除软件自管资料，不创建备份。模型、运行库和外部原件保留。

默认最多30个活动对话，满额请手动移入回收站，不自动挑旧对话淘汰；已有对话可继续发送。回收站默认30天，普通运行日志默认7天；工具审计独立采用365天/1GB规则，不受出厂设置清除；实验和无引用附件另有清理限额。具体以设置和实际清理任务为准，不保证底层安全擦除。

源码、真实模型、Office、云API、内嵌窗口和安装器分别验收。某台主机运行成功不代表所有Windows、GPU或企业透明加密环境都兼容。版权和第三方许可见[README](../README.md)与[LICENSE](../LICENSE)。

## 13. 中途提问、方向调整与排队

“提问用户”是默认勾选的内置工具。资料不足或需要选择时，模型可给出问题及选项；点击选项填入回答后提交，也可以直接输入自定义回答。收到真实回答后模型才继续，不会替用户自动选择。可以跳过问题或停止这一轮。

问题卡片显示在聊天输入区上方，刷新页面会重新读取待答问题。等待时让出模型运行位置，其他对话可继续；本对话后续消息仍按发送顺序排队。

输入框的“发送 / 加入队列”用于下一轮；“调整当前任务”用于补充当前任务的方向。调整在下一次模型请求前生效，已开始的文件或 Office 操作会先完成。若正在等待提问，调整方向会跳过该问题并通知模型按照新要求继续。调整只携带文字，输入区的附件保留供下一轮发送。

## 14. 审计和编辑快照

工具审计记录动作、模型、连接、耗时、结果以及脱敏目标，不保存聊天正文、代码、密钥或完整文件内容。近期记录实时可见，旧记录按批 GZIP 压缩，分页查看时只解压相关批次。保留最长365天、磁盘上限1GB，达到任一条件清理最旧记录；出厂初始化保留审计。

文件修改前保存快照，默认最多100份，同时受容量限额约束。任务栏目可按时间查看并恢复；恢复前也保存当前文件。快照不是企业备份系统，外部软件修改、透明加密和系统故障仍可能影响恢复。
