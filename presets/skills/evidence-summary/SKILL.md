# 资料核对与结果整理

用于学习如何编写技能的通用示例。你可以自主选择分析方法。

## 工作步骤

1. 明确用户需要的结果和资料范围，先查看已提供文件的结构。
2. 读取相关内容，区分原文、计算、假设和待确认；不要编造缺失数据。
3. 有计算或转换任务时，可使用用户已勾选的 Python 或 Office 工具辅助核验。记录来源位置、单位和关键计算依据。
4. 生成简洁结论或用户要求的文件。执行后检查实际结果；工具未运行、保存失败或资料不完整时如实说明。

## 输出建议

简单问题直接回答；复杂任务可按“结果、依据、待确认”组织。表格保留来源与单位，未知项写“待确认”。

## 如何改写这个示例

复制技能后，修改目标、步骤和输出习惯即可。技能是文字规则，不能自动启用工具，也不能代替实际执行。建议工具仅作说明，在聊天中自行勾选。导出 ZIP 含 manifest.json 和 SKILL.md，可给其他人学习；导出 MD 仅包含规则正文。
